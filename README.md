# Agent Stack

A personal collection of AI development tools, agent skills, configurations, scripts, and infrastructure conventions.
The goal of this repository is to keep reusable AI tooling and operational knowledge in one place without over-automating one-time setup.

## Structure

```text
agent-stack/
├── skills/
├── tools/
├── mcp/
├── configs/
├── scripts/
└── README.md
```

## Future Ideas

As the stack grows, this repository may include:

* additional agent skills
* MCP servers
* reusable prompts
* AI CLI configurations
* VPS bootstrap helpers
* Cloudflare/Tailscale automation
* development environment setup
* backup and recovery workflows
* monitoring
* model/provider configuration
* agent evaluation tooling

There is no requirement for every tool or service to become its own skill. Start with the simplest organization and split things out only when they become independently useful.
